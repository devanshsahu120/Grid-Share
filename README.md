# ⚡ Smart Grid Android App

## 📱 Project Demo
![App Demo](images/app_demo.png)

## 📌 Features
- Operator Login
- Complaint Logging
- Solar Production Monitoring
- Energy Consumption Tracking
- Battery Status
- Weekly Predictions

## 🛠️ Tech Stack
- Android (Java/Kotlin)
- Firebase / MySQL
- REST APIs
